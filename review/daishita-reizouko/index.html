台下冷蔵庫は幅と冷凍室の量で選ぶ——弁当屋が新しい作業場で、台下3台とタテ型の冷凍庫1台に分けた記録

2026年10月30日 公開 2026年10月30日 更新 著者：HANABI
PR 本記事はアフィリエイト広告を含みます。実際に使った物は使った感想を、使っていない物は調べた内容として、分けて書いています。
この記事の結論

台下冷蔵庫は、作業台の高さで上に物を置ける業務用の冷蔵庫です。「コールドテーブル」「テーブル形冷蔵庫」とも呼ばれます。今の店では、冷凍と冷蔵が1台に入った台下冷蔵庫を1台使っています。

新しい作業場の見積もりでは、台下の冷凍冷蔵庫を3台と、タテ型の冷凍庫を1台に分けました。並べてみると、台下は幅1200mmと1500mmで価格がほとんど同じで、冷凍の量を増やすならタテ型のほうが1Lあたり約4割安いことが分かりました。

前提：今の店の台下冷蔵庫は1台

私は人口5万人未満の地方都市で弁当・惣菜店を2店舗営んでいます（詳しくはこの人について）。今の店では、フクシマガリレイの台下冷凍冷蔵庫 LCU-151PM-EF（幅1500×奥行450mm、冷凍68L・冷蔵146L）を使っています。開業のとき、ほかの機種とほとんど比べずに、ネットの業務用厨房機器の通販で買いました。

今、新しい作業場の準備を進めていて、冷やす機器をまとめて選び直しました。1台目と2台目の比べ方はコールドテーブルの比べ方の記事に書いたので、この記事では「何台を、どの形で置くか」を書きます。新しい作業場の機器はまだ使っていないので、メーカーの仕様と楽天市場の価格を調べた内容として書きます。価格はどれも2026年10月30日に楽天市場で見たものです。

タテ型の冷凍庫は、床の面積は台下より少し小さいのに、高さを使うので容量は約2.8倍です。1Lあたりの価格は、台下の約693円に対して約393円でした。冷凍の食材や作り置きをまとめて置くなら、タテ型のほうが安く済みます。

一方で、タテ型は上に物を置けず、作業台にはなりません。台下は「冷やす機器」と「作業台」を1台で兼ねられるのが強みです。

今ならこう選ぶ：台下冷蔵庫の見どころ5つ

1. 冷蔵だけか、冷凍冷蔵か

台下冷蔵庫には、冷蔵だけの型・冷凍だけの型・冷凍と冷蔵が1台に入った型があります。今の店も新しい作業場も、冷凍冷蔵の型にしました。

2. 幅は、置き場所が許すかぎり広く

上で並べたとおり、幅1200mmと1500mmの価格の差は約4,000円でした。容量の差に比べて、価格の差はとても小さいです。

3. 冷凍の量が多いなら、タテ型と組み合わせる

台下を何台も並べるより、タテ型の冷凍庫を1台足したほうが、1Lあたりは安くなります。ただし、タテ型には作業台の役目はありません。

4. 電源（単相100Vか三相200Vか）

今回見た台下はどれも単相100Vで、ふつうのコンセント（アース付き）で使えます。タテ型の GRN-124FDX は三相200Vでした。三相200Vの電気が来ていない建物では、電気の工事が要ります。

5. 電気代も、台数分ふくらむ

冷却時の消費電力が24時間続くとして、1kWhあたり31円で計算すると、台下 SUR-LV1561C は1台で月約4,300円、タテ型 GRN-124FDX は月約8,000円が上限の目安です。台下を3台にすると、台下だけで月約1.3万円になります。実際は庫内が冷えると止まる時間があるので、これより少なくなります（計算の仕方は業務用冷蔵庫の電気代の記事に書いています）。

まとめ：台下は手元用、まとめて置く冷凍はタテ型

開業のときは、台下冷蔵庫1台で始めました。新しい作業場の見積もりで並べてみると、台下は幅で価格がほとんど変わらず、冷凍の量を増やすならタテ型のほうが安いことが分かりました。台下は作業台を兼ねる手元用、まとめて置く冷凍の物はタテ型、と分けると、台数と容量を決めやすくなります。

新しい作業場の機器は、使い始めたら使った感想をこの記事に足します。

よくある質問FAQ

台下冷蔵庫とコールドテーブルの違いは何ですか？

同じものを指す呼び方です。作業台の高さ（800mm前後）で、上に物を置いたり作業したりできる業務用の冷蔵庫で、「テーブル形冷蔵庫」とも呼ばれます。冷蔵だけ・冷凍だけ・冷凍冷蔵の型があります。

台下冷蔵庫の幅は1200mmと1500mmのどちらがいいですか？

置き場所が許すなら1500mmが得です。パナソニックの冷凍冷蔵の型で比べると、幅1200mmの SUR-LV1261C が約20.3万円・213L、幅1500mmの SUR-LV1561C が約20.7万円・299Lで、価格の差は約4,000円でした（楽天市場・2026年10月30日）。

冷凍の容量を増やすには、台下冷蔵庫を増やすのとタテ型冷凍庫を足すのと、どちらが安いですか？

1Lあたりではタテ型のほうが安くなります。台下の SUR-LV1561C は1Lあたり約693円、タテ型冷凍庫の GRN-124FDX は約393円でした。ただしタテ型は作業台にならず、三相200Vの電源が要る機種もあります。

台下冷蔵庫の電気代は月いくらですか？

冷却時の消費電力が24時間続くとして、1kWhあたり31円で計算すると、パナソニックの SUR-LV1561C（192W）は月約4,300円が上限の目安です。実際は庫内が冷えると止まる時間があるので、これより少なくなります。
