急速凍結庫は、新しい作業場では今回は買わなかった——冷凍の通販を考える弁当屋が、パナソニックのタテ型とホシザキのブラストチラーを補助金も入れて比べた記録

2026年11月3日 公開 2026年11月3日 更新 著者：HANABI
PR 本記事はアフィリエイト広告を含みます。実際に使った物は使った感想を、使っていない物は調べた内容として、分けて書いています。
この記事の結論

新しい作業場の準備で急速凍結庫を調べ、今回は買わないと決めました。冷凍の通販を始めるのは、作業場を立ち上げてから1年後くらいを考えていて、急速凍結庫はそのときに補助金を使って入れるつもりです。

候補にしたのは、パナソニックのタテ型 BF-K120（403L）です。楽天市場では約45万円からありました。ホシザキのブラストチラー HBC-6TB3-2（158L）は、標準価格が税抜237万円からで、補助金で半分になってもパナソニックより高くなります。一方で、安いパナソニックは補助金のカタログに載っていません。どちらにするかは、まだ決めていません。

補助金のカタログに載っていた急速冷却・急速凍結の機器

前提：今の店には急速凍結庫がない

私は人口5万人未満の地方都市で弁当・惣菜店を2店舗営んでいます（詳しくはこの人について）。今の店には急速凍結庫がありません。今の店では、飲食店営業とそうざい製造業の許可を取っていますが、保健所からブラストチラーが要ると言われたことはありません（許可のことは営業許可の記事に書いています）。

今、新しい作業場の準備を進めています。そこでは、いずれ冷凍の通販を始めたいと考えていて、そのために急速凍結庫を調べました。冷凍の通販を始めるなら、冷凍食品製造業の許可も要ります。始めるかはまだ確定ではありませんが、確定に近いので、許可は先に取る考えです。

急速凍結庫はまだ使っていないので、この記事の比べた部分は、メーカーの仕様と通販の価格を調べた内容です。楽天市場の価格は2026年11月3日に見たものです。

候補にしたパナソニックと、比べたホシザキ

候補にしたのは、パナソニックのタテ型の急速凍結庫 BF-K120 です。比べたのは、ホシザキのテーブル型のブラストチラー HBC-6TB3-2 です。どちらもまだ使っていません。

パナソニックは背の高いタテ型で、容量はホシザキの2.5倍あります。ホシザキは高さ800mmのテーブル型で、上を作業台として使えます。凍らせるだけでなく、加熱した物を冷蔵の温度まで一気に冷やすこともでき、食材の中の温度を測りながら冷やせます。

新しい作業場の見積もりでは、パナソニックの BF-K120 を通販で約52万円と見ていました。容量が大きく、価格がホシザキの半分以下だったからです。

補助金で半分になっても、ホシザキのほうが高い

新しい作業場では、中小企業省力化投資補助金の「カタログ注文型」を、食器洗浄機で申し込んでいます。この補助金は、国のカタログに載っている機器を買うときに、価格の半分までが出る仕組みです。機器を売るお店と一緒に申し込み、決まる前に買った物は対象になりません。

カタログを確かめると、急速冷却・急速凍結の機器は62件ありました。ホシザキのブラストチラーは載っていましたが、パナソニックの急速凍結庫は1つも載っていませんでした。

自分で払う分の目安約52万円約119万円〜

標準価格で計算すると、補助金で半分になってもホシザキは約119万円からで、パナソニックの倍以上になります。実際の価格は売るお店の見積もりで変わりますが、補助金を使うなら、カタログに載っている機種の中から選ぶことになります。

また、この補助金を2回目に使うには、1回目（食器洗浄機）の補助金が支払われ終わってからになります。2回目は条件も上がり、労働生産性を年4%以上伸ばすことや、店の中の一番低い時給を前回から3.5%以上上げることが求められます。

補助金のカタログに載っている物（調べた物）

ホシザキ ブラストチラー＆ショックフリーザー HBC-6TB3-2（テーブル型・158L）

幅1200×奥行750×高さ800mm・三相200V。凍らせるのも、冷蔵の温度まで冷やすのもできて、食材の中の温度を測る棒が付いています。上は作業台として使える高さです。

今回は開業資金から外した

急速凍結庫は、新しい作業場の開業資金の計画から外しました。冷凍の通販を始めるのは、作業場を立ち上げてから1年後くらいと考えているので、そのときに補助金を使って入れるつもりです。

外す前に、借入が希望どおりに通らなかったときに何から諦めるかを決めていました。順番は、予備のお金 → 急速凍結庫 → 製氷機 → 吊戸棚の数 → エアコンの数 です。急速凍結庫は2番目でした。開業資金の内訳は開業資金の記事に書いています。

置き場所は、作業場の奥の部屋に取ってあります。今の冷凍庫の比べ方は業務用冷凍庫の記事に書いています。

電気代の上限の目安

冷却時の消費電力（60Hz）が24時間続くとして、1kWhあたり31円で計算しました。実際は冷やし終わると止まる時間があるので、これより少なくなります（計算の仕方は業務用冷蔵庫の電気代の記事に書いています）。

  • パナソニック BF-K120：月約23,000円
  • ホシザキ HBC-6TB3-2：月約22,000円

まとめ：補助金を使うなら、カタログに載っている機種から選ぶ

急速凍結庫は、新しい作業場では今回は買いませんでした。冷凍の通販を始める1年後くらいに、補助金を使って入れるつもりです。比べてみると、パナソニックのタテ型 BF-K120 は容量が大きく価格も安い一方で、補助金のカタログには載っていませんでした。ホシザキのブラストチラーは補助金で半分になっても、パナソニックより高くなります。どちらにするかは、冷凍の通販の中身が決まってから決めます。

よくある質問FAQ

弁当屋に急速凍結庫は必要ですか？

私の店では、今の店に急速凍結庫はなく、飲食店営業とそうざい製造業の許可を取ったときも、保健所からブラストチラーが要ると言われたことはありません。冷凍の通販を始めるときに入れることを考えています。

急速凍結庫はいくらしますか？

パナソニックのタテ型 BF-K120（403L）は楽天市場で約45〜64万円、ホシザキのブラストチラー HBC-6TB3-2（158L）は標準価格が税抜237万円からでした（楽天市場の新品は約144万円・2026年11月3日）。

急速凍結庫に補助金は使えますか？

中小企業省力化投資補助金のカタログ注文型には、急速冷却・急速凍結の機器が62件載っていて、価格の半分までが出ます。ただし、私が候補にしたパナソニックの急速凍結庫は載っていませんでした。補助金を使うなら、カタログに載っている機種から選ぶことになります。

急速凍結庫とブラストチラーは何が違いますか？

私が比べた2機種では、パナソニックの急速凍結庫 BF-K120 は凍らせる専用のタテ型で、容量は403Lです。ホシザキのブラストチラー HBC-6TB3-2 はテーブル型で、凍らせるのに加えて、冷蔵の温度まで一気に冷やすこともでき、食材の中の温度を測る棒が付いています。容量は158Lです。
